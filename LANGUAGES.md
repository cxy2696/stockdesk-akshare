## 中文

StockDesk 桌面端、iOS 和美股版各自用了更合适的语言和框架。

| 语言 | 主要用途 | 位置 |
| --- | --- | --- |
| Python 3.10+ | FastAPI、行情适配、SQLite、HMM / 渗流、KDJ | `desktop/backend/`、`us/` |
| TypeScript + React | 桌面端 HUB、页面、图表、主题 | `desktop/frontend/src/` |
| Swift + SwiftUI | iOS 原生界面、Swift Charts、本地模型 | `ios/StockDesk/` |
| JavaScript | 美股版仪表盘交互 | `us/static/app.js` |
| CSS / HTML | HUB 视觉、响应式布局、美股页面 | `desktop/frontend/src/styles.css`、`us/static/` |
| YAML | CI 与容器发布流程 | `.github/workflows/` |
| Dockerfile | A 股 / 美股运行镜像 | `desktop/Dockerfile`、`us/Dockerfile` |

## English

StockDesk desktop app, iOS app and US edition each use the language and framework that fit best.

| Language | Used for | Where |
| --- | --- | --- |
| Python 3.10+ | FastAPI, market adapters, SQLite, HMM / percolation, KDJ | `desktop/backend/`, `us/` |
| TypeScript + React | Desktop HUB, pages, charts, themes | `desktop/frontend/src/` |
| Swift + SwiftUI | Native iOS UI, Swift Charts, local models | `ios/StockDesk/` |
| JavaScript | US dashboard interactions | `us/static/app.js` |
| CSS / HTML | HUB visuals, responsive layout, US page | `desktop/frontend/src/styles.css`, `us/static/` |
| YAML | CI and container publishing | `.github/workflows/` |
| Dockerfile | A-share / US runtime images | `desktop/Dockerfile`, `us/Dockerfile` |
