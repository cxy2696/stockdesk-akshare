StockDesk for Windows 1.10.3
- 双击 StockDesk.exe，打开独立原生窗口（Edge WebView2）。
- 点击中央资产中枢：持仓管理 / 资产分析 / 投资建议 / 指数分析。
- 如果 SmartScreen 提示「已保护你的电脑」：点「更多信息」→「仍要运行」。
- 需要 WebView2 Runtime；没有时会退回默认浏览器。
- 双击后没有窗口：运行 StockDesk.exe --browser，并查看 %LOCALAPPDATA%\StockDesk\stockdesk.log。
- 数据目录：%LOCALAPPDATA%\StockDesk
- 文件大小： 52M
