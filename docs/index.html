THE IDEA

Most investing tools add more noise. StockDesk removes it: one HUB, one daily plan, one honest view of your positions — then the models, only when you need them.

02THE DESK

Three questions.
One place to answer them.

Use the tabs to see how the same desk changes with the question you are asking.

Breadth, mood and the day's plan.

Daily Plan opens with the market state, breadth and tomorrow's levels. It tells you whether today is a day to press or a day to wait.

  • Index trend, RSI and support/resistance
  • Breadth, turnover and the strongest sectors
  • A position range, not a prediction
POSITIONS / REVIEW

Your book, without the noise.

Cost, support, pressure, chip distribution and realized P&L in one place. The review page turns the trades into a story you can learn from.

Cost + chipsWhere the crowd is trapped
NAV + drawdownWhat the risk actually looked like
MODELS / DISCIPLINE

Models describe.
They do not predict.

A 3-state HMM on five A-share indices suggests total exposure. Percolation looks for the largest connected cluster of rising stocks, so you can tell diffusion from a few isolated spikes. Per-stock guidance follows your actual holdings.

04START HERE

Pick the shortest path.

Download a release, run a container, or build from source. The guide covers the first five minutes and the daily routine.

Releases → Guide → This site 
# A-share container
docker run --rm -p 8765:8765 \
  -v stockdesk-data:/data \
  ghcr.io/cxy2696/stockdesk-akshare-a-share:latest

# US dashboard
docker run --rm -p 8770:8770 \
  ghcr.io/cxy2696/stockdesk-akshare-us:latest

# From source
cd stockdesk-akshare/desktop
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cd frontend && npm ci && npm run build
cd .. && python main.py
