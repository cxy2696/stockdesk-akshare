EDITIONS

选一个适合你的入口。

macOS

原生窗口，双击即用

pywebview + WebKit，窗口从主屏左上角打开；聊天、笔记、行情互不打扰。

Windows

单文件 exe

Windows 10/11 使用 Edge WebView2 原生窗口；Win7/8 会自动退回浏览器。

iOS

装在口袋里的 HUB

SwiftUI + Swift Charts，数据在手机本地；支持 100/120/150% 字体缩放。

US

美股独立版

道指、纳指、标普、自选、K 线、异动榜；独立端口，不碰 A 股数据。

Docker

A 股 / 美股容器

两个 GHCR 镜像，挂载一个数据卷就能跑；适合 NAS 或服务器。

MIT

代码是开放的

可以读、改、自己打包；欢迎提 issue 或 PR。

QUICK START

最短的一条路。

不想看长文档？先下载 Release，或者用 Docker 跑起来。

macOS / Windows
# 下载 Release 中的
# StockDesk-macOS-1.9.0.zip
# StockDesk-Windows-1.9.0.exe

# 解压 / 双击即可
A-share · Docker
docker run --rm -p 8765:8765 \
  -v stockdesk-data:/data \
  ghcr.io/cxy2696/stockdesk-akshare-a-share:latest
US · Docker
docker run --rm -p 8770:8770 \
  ghcr.io/cxy2696/stockdesk-akshare-us:latest
From source
git clone https://github.com/cxy2696/stockdesk-akshare
cd stockdesk-akshare/desktop
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd frontend && npm ci && npm run build
cd .. && python main.py
