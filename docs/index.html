STOCKDESK / HUB

宽度、情绪，和今天的计划。

每日策略先给出市场状态、涨跌宽度和明天的关键位。它告诉你今天是该进攻，还是该等一等。

  • 指数趋势、RSI 与支撑/压力
  • 涨跌宽度、成交额与最强板块
  • 仓位区间，而不是一句预测

INSTALL.TXT 
# A-share container
docker run --rm -p 8765:8765 \
  -v stockdesk-data:/data \
  ghcr.io/cxy2696/stockdesk-akshare-a-share:latest

# US dashboard
docker run --rm -p 8770:8770 \
  ghcr.io/cxy2696/stockdesk-akshare-us:latest

# From source
cd stockdesk-akshare/desktop
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cd frontend && npm ci && npm run build
cd .. && python main.py
