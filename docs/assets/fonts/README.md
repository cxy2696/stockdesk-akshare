# Bundled fonts · 内置字体

[中文](#中文) · [English](#english)

## 中文

展示页使用两套 SIL Open Font License 1.1 字体，均放在本地，不请求第三方字体服务：

| 字体 | 用途 | 许可证 |
| --- | --- | --- |
| Instrument Serif | 展示页标题衬线 | `OFL-InstrumentSerif.txt` |
| IBM Plex Mono | 标签、时间码、数字 | `OFL-IBMPlexMono.txt` |

来源：[Google Fonts](https://fonts.google.com/)、[Instrument](https://github.com/Instrument/instrument-serif)、[IBM Plex](https://github.com/IBM/plex)。

## English

The project site bundles two SIL Open Font License 1.1 families locally; no third-party font service is called at runtime.

| Family | Used for | License |
| --- | --- | --- |
| Instrument Serif | Editorial display headings | `OFL-InstrumentSerif.txt` |
| IBM Plex Mono | Labels, timecodes, numerals | `OFL-IBMPlexMono.txt` |

Source: [Google Fonts](https://fonts.google.com/), [Instrument](https://github.com/Instrument/instrument-serif), [IBM Plex](https://github.com/IBM/plex).
